# Plumed 0.2.0-beta.1 (2026-11-23)

**🔒 Removed: network access and data leaving the machine** (Plumed is local-first, so features that open network access were removed to reduce the attack surface)

- **Local API**: the local HTTP server (Extensions > Local API) and its transcription endpoints are gone. Settings files and `.murmure` exports that still contain its options load without errors.
- **Command Mode and Prompt Mode (LLM Connect)**: everything that sent text to an LLM is gone: Ollama and remote LLM servers, the Command and Prompt shortcuts, CLI flags and wake words, and the SmartMic LLM and live translation modes (SmartMic is now pure dictation). The "Show result after dictation" setting keeps Off and All dictations; the old Command choices become Off. Old settings and `.murmure` exports with LLM options still load, the options are ignored. Plumed does not delete what it left on your computer: `llm_connect.json` in the app data folder and the `plumed` keyring entry holding a remote server API key, remove them by hand if you want.
- **SmartMic**: the phone microphone over the local network (its local HTTPS server, QR pairing, paired devices, reverse proxy relay settings and phone page) is gone, replaced by the end-to-end encrypted phone microphone through a relay. Old settings and `.murmure` exports with SmartMic options still load, the options are ignored. Plumed does not delete the SmartMic certificate and paired devices it left in the app data folder (`smartmic` folder), remove it by hand if you want.
- **Voice Mode**: hands-free wake word listening is gone, with its page, its toggle shortcut and the `--voice-mode` CLI flag. Old settings and `.murmure` exports with Voice Mode options still load, the options are ignored.

**✨ New Features**

- **App update channel**: Settings > Online > App updates offers stable versions (default), beta versions (pre-releases, which then lead to the final release) or no automatic check (a sidebar button then checks on demand). The "Check for updates" button only shows when an update is available or the check is disabled. When GitHub is unreachable, the check and the download go through the Plumed relay (models.plumed.fr); the installer signature is still verified, so the relay cannot forge an update.
- **Speech model downloaded on first launch**: the installer no longer ships the speech model, so it is much smaller. On first launch a dialog lets you pick a model (UltiMed v2 Ultra int8, 668 MB, or the lighter w4a8, 402 MB) and downloads it once, with progress, resume after an interruption and SHA-256 checks. The model is kept across updates.
- **Model tab**: Settings > System > Model shows the catalog and lets you switch, check, re-download or delete a model.
- **Model recommended for your computer**: on computers with less than 8 GB of RAM, the lighter w4a8 model is preselected and marked "Recommandé" (it uses about 20% less memory). Each model now says what it saves: download size, memory, accuracy.
- **ONNX Runtime 1.31**: the inference library moves from 1.23.2 to 1.31.0 (`ort` 2.0.0-rc.15), with its telemetry explicitly turned off.
- **Model relay**: when Hugging Face is blocked (common on corporate and institutional networks), the download goes through the Plumed relay `models.plumed.fr`, which streams the same files and logs nothing.
- **Beam search**: final transcriptions are decoded with a beam of 5 hypotheses instead of greedy decoding, each with its own phrase boosting state. Slightly more accurate on French medical dictation (mostly on drug names), for about 10% more decoding time. The live preview stays greedy.
- **Sound-alike medical words**: when a decoded word is a known mishearing of several medical terms ("singulaire": Singulair or cingulaire), Plumed listens to that passage again and keeps the term the audio supports (option "Resolve sound-alike medical words").
- **Text templates**: new last tab of the Corrections page (no step number). A spoken phrase is replaced by a longer, possibly multi-line text, applied at the start of step 6 before your formatting rules ("Insère l'examen clinique normal." gives a complete normal clinical exam; this example ships turned off). Search, add, edit, delete, turn on or off, import, export and reset to the original list; the changes travel in the settings export.
- **Grammar step**: a new last step, 7 Grammaire, fixes agreement errors with the Grammalecte grammar checker ("La patiente de 63 ans est fatigué" becomes "fatiguée"). Only fixes with a single suggestion are applied, for 8 rules measured as helpful on medical dictations; ages, doses, acronyms and names are hidden from the checker so it does not take them for errors, and typography is never changed. The Grammar tab of the Corrections page turns the step off, or turns other rules on, each shown with how often it helped or hurt; the changes travel in the settings export. Grammalecte runs inside Plumed, offline, without Python.
- **No microphone? Use your phone**: when no microphone is found at startup, Plumed offers the phone microphone (alpha, avoid sensitive content) and reminds that any microphone under 5 euros works. Asked again after each update until a microphone is found.
- **Corrections page**: the Dictionary and Formatting Rules pages are now one Settings > Corrections entry with one tab per list. Explanation shows every step that changes the text as a card with a concrete before and after example, in the order the code runs them, linked by arrows (medical vocabulary boosting, sound-alike words, personal dictionary spelling, clean-up and standardization, residual errors, your formatting rules), with its on/off state and a button to its list. Medical vocabulary (the ~77,000 boosted phrases), Sound-alike words (the confusion groups), Personal dictionary, Residual errors (the UltiMed and Plumed rules) and Formatting each have a search, their on/off option, Import, Export (in the list's own format) and "Back to the original list". A bundled phrase or group can be turned off and your own added, stored apart (`medical_phrases.json`, `medical_confusion_groups.json`) and kept across medical data updates.
- **PhoneMic**: the phone microphone is now called PhoneMic everywhere (sidebar, page, startup prompt, phone page, docs). Settings are unchanged.
- **Relay choice**: enabling the phone microphone now asks which relay to use (Plumed's, built in, or your institution's own), explains that the audio is encrypted on the phone and only readable by Plumed on this computer, and that the relay is not an HDS server.
- **UltiMed v2**: Plumed now ships the UltiMed v2 model (French medical fine-tune of Parakeet TDT 0.6B v3) and its v2 drug and medical term fix rules (release v2.0.2 of the rules repo): 45,110 rules in six files (drugs, dictionary, PARHAF, PARROT, acronyms, then the hand-written file, which now runs last so its spelling conventions also respell what a learned rule wrote), instead of the 41,744 v1 rules. The rules are now AGPL-3.0-or-later. Your edits of v1 rules that no longer exist in v2 are dropped (no migration).
- **Anonymous usage statistics (opt-in)**: Plumed asks once whether to share anonymous usage statistics with its maintainer, off unless you say yes and changeable anytime in Settings > System > Advanced. Only aggregated daily counts are sent (number and length of dictations, errors, version, system, features on), never text, audio or patient data; a button shows exactly what is sent, and turning it off deletes the local counters and random id.
- **Medical rules updates**: on first launch Plumed asks whether it may check for medical rules updates at each start (nothing is contacted before you answer; existing installs are asked once too). If you agree, at startup it asks GitHub whether newer drug and medical term rules exist for its model (no identifier sent, can be turned off in Settings > System > Online) and offers them in a dialog: nothing is downloaded without your click. When the check fails (network, GitHub blocked, bad signature), a notice says so once per launch with a link to the release page; the settings show the last check, and "Install a downloaded update" installs the files downloaded with your browser, checked exactly like an online update. The files are signed and checked before use, switch live without a restart, and your own edits are kept (edits of rules that no longer exist are marked in the rules editor). "Return to the bundled data" undoes it.

- **Clearer Corrections page**: six steps, one per tab, each tab showing its step number in a small badge: 1 Medical vocabulary, 2 Sound-alike words, 3 Personal dictionary, 4 Clean-up and standardization, 5 Residual errors (formerly Model corrections), 6 Formatting. Short text correction and the pre-installed formatting are options of step 4 (shown with when they really run, after steps 5 and 6), also in the history. The pre-installed options (hesitations, short text, spaces, numbers) get their own Clean-up and standardization tab, which replaces the "Show the pre-installed rules" switch of the formatting rules tab (that switch only hid those options, below the InterHop rules). The "Your formatting rules" heading folds its list. New examples for the personal dictionary and hesitation steps.
- **What each step changed, in the history**: an arrow on each recent transcription of the home page shows one line per processing step, saying whether the step changed the text, with the removed words in red and the added words in green. Works for keyboard and PhoneMic dictations. The texts follow the history rules (in memory, on disk only with "Persist history").
- **Text typed by default**: new installs insert the text by typing it (Direct) instead of Ctrl+V, so the clipboard is left alone. Wayland keeps Ctrl+V (Direct is experimental there). Existing settings are unchanged.
- **System settings in tabs**: General, Overlay, Advanced, Online and the keyboard shortcuts are now five tabs of the System page; the separate Shortcuts entry of the sidebar is gone.
- **Online tab**: Settings > System > Online says what goes online and when (the app update check at every start, which cannot be turned off, the medical data update check and the usage statistics, both off unless you agreed, and PhoneMic's relay), and holds the usage statistics and medical data update settings, moved from the end of the Advanced tab and from the Corrections page.
- **Corrections lists in the settings export**: the `.murmure` export and import (and `plumed import`) now carry your changes to the medical vocabulary, the sound-alike words and the residual errors, one category each named after its tab, checked like an import in that tab. Only your changes are exported, never the provided lists. Older `.murmure` files import as before.
- **Getting started checklist removed**: the "Getting started" checklist of the sidebar is gone. The startup questions (PhoneMic, usage statistics, medical data) and the Wayland setup help stay.
  **🐛 Bug Fixes**
- **PhoneMic**: dictations made with the phone microphone now appear in the home page history and count in the stats and usage statistics, like keyboard dictations.
- **French previews**: the overlay preview text and the examples of the clean-up options were in English in the French interface; they are now French medical examples.
  **🔒 Security**
- **Recordings folder per user**: the temporary audio files are no longer in the shared temporary folder (`/tmp/plumed_recordings` on Linux), where another account of the computer could create the folder first. They now go to a folder of your own account: on Linux the session runtime folder (`$XDG_RUNTIME_DIR/plumed_recordings`, in memory, erased at logout), otherwise `plumed_recordings` in the Plumed cache folder. "Keep audio recordings" keeps them there too. An old `/tmp/plumed_recordings` folder is left untouched, you can delete it.
- **Content Security Policy**: the app windows now run under a strict Content Security Policy: only the app's own scripts, styles, images and the connection to the Plumed core are allowed, no remote site, no frame, no plugin. Network calls (updates, PhoneMic relay, statistics) are made by the Rust core, not by the interface, so they are not affected.
- **Command-line import off by default**: on a new install, `plumed import` is refused until you turn off "Block command-line import" (Settings > System > Advanced), so another program running on your account cannot silently replace your settings. The error message says how to allow it. Existing installs keep their current choice. Importing from the app window is unchanged.
- **Recording overlay restricted**: the small recording overlay window can now only call the few commands it needs (read settings, cancel, hide, show the result panel) instead of every command of the app.
- **PhoneMic late transcripts are not pasted**: if a PhoneMic transcript is ready more than 20 seconds after the end of the phone recording, it is kept in the history but not pasted, so it cannot land in another application or field you moved to. A notice tells you.
- **Build actions pinned**: the GitHub Actions used to build the releases are pinned by commit hash instead of a movable tag, so a compromised action tag cannot change what builds Plumed; Dependabot proposes the updates weekly.
- **Wayland typing permission (Linux)**: the Linux packages (deb, rpm, Arch) no longer install a udev rule giving keyboard injection (`/dev/uinput`) to the `input` group. When direct typing on Wayland is unavailable, Plumed shows the command that installs a narrower rule (`/etc/udev/rules.d/60-plumed-uinput.rules`): only the user of the active local session gets access, through `TAG+="uaccess"`, no group. Upgrading the package removes the old `/usr/lib/udev/rules.d/60-plumed-uinput.rules` automatically (it was owned by the package), so on Wayland direct typing needs that command once after the upgrade; the old permission disappears at the next reboot. If you ran the previous command shown by the app, run the new one (it replaces the file) or remove it: `sudo rm /etc/udev/rules.d/60-plumed-uinput.rules`.
- **Stricter checks on imported lists**: formatting rule replacements (line breaks and tabs still allowed), dictionary words and sound-alike groups can no longer contain control characters, which could act as keys (Backspace, Escape, Enter) when the text is typed; such entries or files are refused with a message. A sound-alike group has at most 20 candidates, and a list accepts at most 50,000 entries of your own (formatting rules, dictionary words, added phrases, groups or rules), so a huge file is refused instead of slowing every dictation down.
- **Private data folder (Linux)**: the Plumed data folder (settings, lists, history when kept on disk, logs) is now readable by your account only. It used to follow the default permissions, so on a computer whose home folders are open to other accounts (older Ubuntu, accounts of a hospital directory), another user could read the history of dictations.
- **Invisible characters refused**: imported lists and rules can no longer carry invisible characters (soft hyphen, zero-width space, bidi marks, Unicode tags) either, and Direct typing drops them: hidden inside a drug name, they kept it from matching a search of the patient record, or carried text nobody sees. The narrow no-break space of French typography is still allowed.
