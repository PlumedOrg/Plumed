# Changelog

Release notes live in [`changelog/`](./changelog/), one folder per version, each holding a single `CHANGELOG.md` starting with `# Plumed <version> (YYYY-MM-DD)`.

Folders named `murmure-<version>` are the releases of the upstream project Plumed is forked from.

To write the notes for a new release, create `changelog/<version>/CHANGELOG.md`. Never edit this file to add notes: keeping one file per version stops the changelog from growing without bound.
